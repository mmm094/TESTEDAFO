# Simulacro de Examen — Edafología

Aplicación web para practicar el examen tipo test de **Edafología** (Ciencias Ambientales).

## Características

- **151 preguntas** del banco completo (recopilatorio 197 + exámenes 2017–2025)
- Selección aleatoria de **40 preguntas** por simulacro, garantizando cobertura de todos los temas
- Sistema de penalización: **acierto +1 / error −0,5** (×2 errores resta 1)
- Marcador en tiempo real durante el examen
- **Análisis por temas** al finalizar, ordenado de peor a mejor rendimiento
- Diseño profesional responsive (móvil y escritorio)

## Temas incluidos

| Tema | Contenido |
|------|-----------|
| 1 | Perfil, horizontes y nomenclatura |
| 2 | Componentes inorgánicos, minerales y arcillas |
| 3 | Materia orgánica y humus |
| 4 | Agua del suelo |
| 5 | Aireación y fase gaseosa |
| 6 | Textura y análisis granulométrico |
| 7 | Estructura, consistencia y color |
| 8 | Intercambio catiónico, CIC y bases |
| 9 | pH, Eh y reacción del suelo |
| 10 | Factores formadores y edafogénesis |
| 11 | Prácticas y análisis de laboratorio |

## Despliegue en GitHub Pages

1. Sube los archivos a un repositorio GitHub
2. Ve a **Settings → Pages**
3. En *Source*, selecciona `main` branch y carpeta `/ (root)`
4. Guarda y la URL estará disponible en `https://TU_USUARIO.github.io/NOMBRE_REPO`

## Estructura de archivos

```

├── js/
```
